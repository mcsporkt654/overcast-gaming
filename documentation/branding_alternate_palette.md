# Overcast Wargaming League — Brand Guide

Brand System · Portland, OR
Visual identity, color palette, and favicon set for the Warhammer 40,000 league under the Pacific Northwest sky.

---

## 01. Color Palette

### Core / Surfaces & Brand Teals

| Name | Hex | Usage |
|---|---|---|
| Void | `#0A0C0C` | Page background, deepest layer |
| Midnight Petrol | `#06201D` | Cards, tiles, raised panels |
| Deep Petrol | `#04302C` | Owl body · section fills |
| Storm Teal | `#0C4E48` | Primary brand color |
| Sea Teal | `#157068` | Hover · borders · lift states |

### Accents / Use with Restraint

| Name | Hex | Usage |
|---|---|---|
| Arc Cyan | `#26E3FE` | Primary accent · CTAs · glow & links |
| Witchlight | `#D0DA27` | The owl's eye · spark accent, rare |

### Neutrals / Text & Fog

| Name | Hex | Usage |
|---|---|---|
| Bone | `#F4F6F5` | Owl face · primary text on dark |

## 02. Favicon

**Owl Face** — *Recommended*
Cropped straight from the mark — the two-tone face, lime eye, and cyan brim make it unmistakably Overcast. Richest at 32px and up.
Sizes: 512 / 64 / 32 / 16

**Eye Monogram** — *Alt, tiny sizes*
Abstracts the owl's eye into a glowing "O" — stays crisp and legible down to 16px where the detailed face gets busy.
Sizes: 512 / 64 / 32 / 16

*In context (browser tab):* Overcast Wargaming League

## 03. Type & Usage

**Oswald** — Display · Headings · Wordmark
Condensed & bold — echoes the logo lettering.

**Barlow** — Body · UI · Long-form
Clean, low-contrast humanist sans that stays readable for schedules, rosters, and rules.

---

## Do / Don't

**Do**
- Keep the mark on Void or Petrol dark backgrounds.
- Let Arc Cyan carry the glow — links, borders, key CTAs.
- Reserve Witchlight for one small spark per view.

**Don't**
- Place the mark on light or busy photo backgrounds.
- Flood large areas with cyan or lime.
- Recolor the teals or add extra hues.
